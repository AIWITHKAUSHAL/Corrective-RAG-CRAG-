WHY THE LOOP STOPS
Corrections have a budget.
Quality is a routing heuristic
Accepted documents ÷ retrieved documents. An empty batch scores zero. At the default 50% threshold, the graph generates from accepted evidence. This score is not model confidence or a guarantee of accuracy.
Two corrections by default
The first correction rewrites the query and switches to BM25. If that still fails, the second can use Tavily when enabled and configured. Every batch is graded again. At the limit, generate from accepted evidence with a limitation notice, or report insufficient evidence.
